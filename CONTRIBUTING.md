# Contributing to X AI Agent

Thanks for helping improve an open source X (formerly Twitter) AI Agent toolkit.

## Development workflow

1. Fork the repository and clone your fork.
2. Install Node.js 20+ and run `npm install`.
3. Create a focused branch, for example `feat/provider-adapter`.
4. Run `npm run build`, `npm test`, and `npm run lint` before opening a PR.
5. Explain the user problem, the approach, and safety implications in your PR.

## Issues and pull requests

- Use the bug report template for reproducible defects.
- Use the feature request template for proposals and include a use case.
- Keep changes small and documented with tests where behavior changes.
- Never include API keys, cookies, OAuth secrets, or X session tokens.
- PRs should preserve manual approval defaults and platform compliance.
